One-Liner Laugh Lab: write one short funny line, max 200 characters, that answers the prompt "the excuse a robot vacuum gives after eating a sock". The funniest, most original line wins. `main.py` writes the line (UTF-8, no trailing newline) to `/output/entry.txt` — see [make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae).

## Run it
